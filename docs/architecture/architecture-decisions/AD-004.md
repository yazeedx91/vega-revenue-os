# AD-004: Tenant Context Propagates Across All Layers

- **Decision ID:** AD-004
- **Status:** Proposed
- **Date:** 2026-08-08
- **Owner:** Enterprise Architecture Board

## Decision

Every request, event, command, database operation, cache key, vector search, object storage path, audit record, and analytics projection will carry explicit tenant context. Cross-tenant access is impossible by default.

## Context

The platform is multi-tenant by design. ADR-054 mandates strong tenant isolation.

## Alternatives

1. Tenant only at API gateway
2. Tenant context propagated everywhere
3. Separate infrastructure per tenant

## Rationale

Option 2 provides strong isolation without the cost of separate infrastructure per tenant. It is enforced at every layer.

## Impact

- API Gateway extracts tenant and propagates it.
- Events and commands include tenant ID.
- Database uses per-tenant schemas or RLS.
- Cache, vector, object storage, and audit are tenant-scoped.
- Cross-tenant operations by platform admins are explicit and audited.
