# AD-005: Durable Workflows for Long-Running Missions

- **Decision ID:** AD-005
- **Status:** Proposed
- **Date:** 2026-08-08
- **Owner:** Enterprise Architecture Board

## Decision

Long-running missions will be implemented using a durable workflow engine with explicit state persistence, checkpointing, pause/resume, cancellation, timers, and compensation. Missions may not depend on a single continuously running process.

## Context

Missions can run from seconds to weeks. A single process cannot reliably run that long.

## Alternatives

1. Long-lived process per mission
2. State machine in database with manual orchestration
3. Durable workflow engine

## Rationale

A durable workflow engine provides built-in persistence, timers, human tasks, and recovery. It avoids custom orchestration bugs.

## Impact

- Mission state persisted after each step.
- Workers can be restarted without losing progress.
- Pause/resume/cancel supported.
- Compensation actions defined for partial work.
- Workflow engine technology to be selected in Phase 05.
