# ADR-040-R: Rely on model pre-trained knowledge (Rejected)

- **ADR ID:** ADR-040-R
- **Status:** Rejected
- **Date:** 2026-08-08
- **Decision Owners:** Architecture Board

## Context

This document records the alternative that was rejected for External Research and Web Crawling.

## Problem

The same problem as ADR-040: External Research and Web Crawling.

## Decision

Reject Rely on model pre-trained knowledge in favor of the alternative selected in ADR-040.

## Rationale

A dedicated service isolates research from core, respects rate limits, and keeps AI responses grounded in current sources.

## Consequences

This option is not implemented. The accepted path is documented in [ADR-040](decisions/ADR-040.md).
