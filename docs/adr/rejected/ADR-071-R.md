# ADR-071-R: Bare metal deployment (Rejected)

- **ADR ID:** ADR-071-R
- **Status:** Rejected
- **Date:** 2026-08-08
- **Decision Owners:** Architecture Board

## Context

This document records the alternative that was rejected for Container and Packaging.

## Problem

The same problem as ADR-071: Container and Packaging.

## Decision

Reject Bare metal deployment in favor of the alternative selected in ADR-071.

## Rationale

Containers provide portability, reproducibility, and a strong isolation boundary for the runtime.

## Consequences

This option is not implemented. The accepted path is documented in [ADR-071](decisions/ADR-071.md).
