# ADR-080-R: Manual QA only (Rejected)

- **ADR ID:** ADR-080-R
- **Status:** Rejected
- **Date:** 2026-08-08
- **Decision Owners:** Architecture Board

## Context

This document records the alternative that was rejected for Automated Testing Strategy.

## Problem

The same problem as ADR-080: Automated Testing Strategy.

## Decision

Reject Manual QA only in favor of the alternative selected in ADR-080.

## Rationale

A layered automated test strategy catches issues early and supports safe, frequent releases.

## Consequences

This option is not implemented. The accepted path is documented in [ADR-080](decisions/ADR-080.md).
