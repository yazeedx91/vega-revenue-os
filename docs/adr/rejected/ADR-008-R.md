# ADR-008-R: Full-stack server-rendered application (Rejected)

- **ADR ID:** ADR-008-R
- **Status:** Rejected
- **Date:** 2026-08-08
- **Decision Owners:** Architecture Board

## Context

This document records the alternative that was rejected for Backend and Frontend Separation.

## Problem

The same problem as ADR-008: Backend and Frontend Separation.

## Decision

Reject Full-stack server-rendered application in favor of the alternative selected in ADR-008.

## Rationale

A clear backend/frontend split improves security, enables multi-channel clients, and centralizes authorization and audit.

## Consequences

This option is not implemented. The accepted path is documented in [ADR-008](decisions/ADR-008.md).
