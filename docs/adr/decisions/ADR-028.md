# ADR-028: Structured Output and Parsing

- **ADR ID:** ADR-028
- **Status:** Accepted
- **Group:** AI
- **Date:** 2026-08-08
- **Decision Owners:** Architecture Board, CTO

## Context

The AI-Native Autonomous Revenue Employee requires clear ai direction so that implementation, operations, and future evolution remain coherent. This ADR captures the relevant drivers, alternatives, and consequences for the structured output and parsing concern.

## Problem

Multiple ai options exist for structured output and parsing. Without a documented decision, individual teams may choose inconsistent technologies or patterns, creating integration debt, security gaps, and operational sprawl.

## Requirements

- Produce machine-readable output
- validate structure
- recover from parsing failures

## Decision

Require JSON schema or tool-calling outputs, validate against schema, and parse with fail-safe fallbacks.

## Alternatives

1. **Free-text generation with manual parsing**
2. **XML-structured output**

## Rationale

JSON schema and tool calling maximize reliability, type safety, and downstream integration while reducing parsing ambiguity.

## Consequences

This decision aligns the ai domain with the overall architecture. It enables consistency, reduces cross-cutting risk, and leaves room to revisit alternatives when validation data is available.

## Risks

- Model compliance with schema
- schema churn

## Mitigations

- Fallback prompts
- re-prompting
- strict validation
- schema versioning

## Security Impact

Provider keys, prompt data, and outputs are isolated per tenant; all high-impact actions require explicit approval.

## Performance Impact

Model routing and caching reduce both latency and cost by selecting the smallest capable model for the task.

## Scalability Impact

A multi-provider abstraction and tool registry let us add models and capabilities without core rewrites.

## Cost Impact

Usage is metered per tenant; cheaper models handle routine tasks and expensive models are reserved for complex reasoning.

## Operational Impact

Prompt versioning, model health checks, and fallback chains make AI services observable and maintainable.

## AI Impact

Structured output, confidence scoring, and citations are first-class concerns, directly improving agent reliability.

## Reversibility

Medium. The decision can be revisited when validation criteria or operational constraints change; alternatives are documented and can be re-evaluated.
