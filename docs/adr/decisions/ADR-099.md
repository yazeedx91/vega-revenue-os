# ADR-099: Evidence as a First-Class Provenance Value Object

- **ADR ID:** ADR-099
- **Status:** Accepted
- **Group:** AI / Intelligence
- **Date:** 2026-08-09
- **Decision Owners:** Architecture Board, CTO

## Context

The AI-native engine must produce evidence-backed recommendations. Without a structured model, hallucinated or stale claims can pollute lead scores and downstream outreach.

## Decision

1. `ResearchEvidence` is an immutable domain value object containing claim, normalized value, source, reliability tier, observed/freshness timestamps, confidence breakdown, provenance chain, and contradictions.
2. Raw provider payloads are translated into `ResearchEvidence` at the adapter boundary. No HTML, screenshots, or opaque blobs enter domain logic.
3. Every lead qualification decision must reference one or more evidence IDs.
4. Confidence is computed as a combination of source reliability, extraction confidence, and corroboration.

## Alternatives

1. Store raw provider responses and let agents decide. Rejected: impossible to audit or re-score deterministically.
2. Use a single scalar confidence. Rejected: explainability and debugging require a breakdown.

## Rationale

A structured evidence model makes every consequential decision traceable, testable, and reproducible.

## Consequences

- Lead scores can be explained by listing evidence.
- Stale evidence can be re-fetched or down-weighted.

## Risks

- Evidence volume can grow; repository must support efficient account/contact queries and TTL expiration.

## Security Impact

Evidence carries tenant-scoped provenance and is subject to the same isolation rules as other aggregates.

## Performance Impact

Small overhead per account/contact. Caching reduces repeated provider calls.

## Scalability Impact

Evidence repository may need sharding by tenant/account in production.

## Cost Impact

Low; evidence objects are small and cached.

## Operational Impact

Operations can inspect evidence chains to understand why a lead was qualified.

## AI Impact

Forces agents to produce normalized, auditable claims rather than opaque summaries.

## Reversibility

Medium. The model is a value object; changing it later requires migrating existing evidence records.
