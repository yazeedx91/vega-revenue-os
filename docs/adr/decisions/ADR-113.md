# ADR-113: Intent Classification Autonomy and Human Escalation

- **ADR ID:** ADR-113
- **Status:** Proposed
- **Group:** Conversation / AI Control Plane
- **Date:** 2026-08-12
- **Decision Owners:** Architecture Review Board, CTO

## Context

The system must autonomously classify prospect replies, but misclassification can wrongfully qualify or disqualify leads. Phase 13 needs explicit confidence and autonomy thresholds.

## Decision

1. Use a deterministic, rule-based `IIntentClassifier` in Phase 13; real LLM classification remains a port.
2. Define `IntentClassification` with `intent`, `confidence`, and `reason` fields.
3. Use `INextBestActionPolicy` to map intent + autonomy level to an action.
4. Escalation rules:
   - Confidence < 0.60 always escalates to a human.
   - 0.60 ≤ confidence < 0.85 escalates if autonomy level < 2 or the reply is ambiguous.
   - Opt-out is handled automatically but logged for compliance review.
5. Disqualification and re-qualification of leads require high confidence and an explicit intent signal.

## Alternatives

1. Use a real LLM for intent classification immediately. Rejected: cost, latency, and non-determinism complicate early testing and audit.
2. Allow any autonomous action when confidence exceeds 0.5. Rejected: too permissive for lead-state changes.

## Rationale

Deterministic classification with explicit thresholds provides an auditable safety boundary and can be replaced by an LLM-backed adapter later without changing the domain model.

## Consequences

- All classifications are explainable by rules.
- Human escalation volume may be high until the classifier improves.
