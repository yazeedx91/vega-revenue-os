# ADR-106: Reuse Phase 10 Approval Boundary for Outreach Gates

- **ADR ID:** ADR-106
- **Status:** Proposed
- **Group:** AI / Outreach
- **Date:** 2026-08-12
- **Decision Owners:** Architecture Review Board, CTO

## Context

Phase 12 must not send external communications without approval. A new approval model would duplicate the existing Phase 10 `Approval` aggregate and service.

## Decision

1. Reuse the existing `Approval` aggregate and `ApprovalApplicationService` from `packages/mission-orchestrator`.
2. Represent outreach approval requests with new `actionType` policy identifiers:
   - `outreach-campaign-approve`
   - `outreach-sequence-approve`
   - `outreach-message-send`
3. The outreach execution service creates approval requests before any external provider submission and checks approval status before transitioning `OutreachMessageExecution` to `APPROVED`/`QUEUED`.
4. Approval decisions are immutable domain events; bypass via duplicate commands, retries, or workflow replay is prevented by idempotency keys and aggregate state checks.

## Alternatives

1. Create an outreach-specific approval aggregate. Rejected: duplicate concept, fragmented audit trail.
2. Implement approval as a simple workflow signal only. Rejected: decisions must be auditable domain artifacts.

## Rationale

One approval model across missions and outreach keeps the architecture coherent, leverages Phase 10 testing, and ensures a single source of truth for human-in-the-loop decisions.

## Consequences

- Outreach gates are first-class domain events.
- The orchestrator can wait for approval signals the same way it waits for mission task approvals.
- New `actionType` values may require UI updates; this is an intentional lightweight extension point.

## Risks

- If the approval model changes in the future, both missions and outreach are affected; this is acceptable because the model is intentionally shared.

## Security Impact

No change; approvals remain tenant-scoped and event-sourced.

## Performance Impact

No additional overhead.

## Scalability Impact

None.

## Cost Impact

None.

## Operational Impact

Operations and compliance use a single approval dashboard for all missions and outreach.

## AI Impact

Human-in-the-loop review for AI-generated outreach is supported without custom code.

## Reversibility

High. Action types are additive strings.
