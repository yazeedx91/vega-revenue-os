# ADR-027: Tool Registry

- **ADR ID:** ADR-027
- **Status:** Accepted
- **Group:** AI
- **Date:** 2026-08-08
- **Decision Owners:** Architecture Board, CTO

## Context

The AI-Native Autonomous Revenue Employee requires clear ai direction so that implementation, operations, and future evolution remain coherent. This ADR captures the relevant drivers, alternatives, and consequences for the tool registry concern.

## Problem

Multiple ai options exist for tool registry. Without a documented decision, individual teams may choose inconsistent technologies or patterns, creating integration debt, security gaps, and operational sprawl.

## Requirements

- Discover tools
- enforce schemas
- scope by tenant
- version tools

## Decision

Maintain a typed, versioned tool registry with JSON schemas, capability metadata, and tenant scoping.

## Alternatives

1. **Hard-coded tool calls**
2. **Untrusted arbitrary plugins**

## Rationale

A registry makes tools discoverable, safe, and versioned. Agents can only invoke registered, approved tools.

## Consequences

This decision aligns the ai domain with the overall architecture. It enables consistency, reduces cross-cutting risk, and leaves room to revisit alternatives when validation data is available.

## Risks

- Schema maintenance
- permission boundary confusion

## Mitigations

- Schema validation
- approval workflows
- clear capability metadata

## Security Impact

Provider keys, prompt data, and outputs are isolated per tenant; all high-impact actions require explicit approval.

## Performance Impact

Model routing and caching reduce both latency and cost by selecting the smallest capable model for the task.

## Scalability Impact

A multi-provider abstraction and tool registry let us add models and capabilities without core rewrites.

## Cost Impact

Usage is metered per tenant; cheaper models handle routine tasks and expensive models are reserved for complex reasoning.

## Operational Impact

Prompt versioning, model health checks, and fallback chains make AI services observable and maintainable.

## AI Impact

Structured output, confidence scoring, and citations are first-class concerns, directly improving agent reliability.

## Reversibility

Medium. The decision can be revisited when validation criteria or operational constraints change; alternatives are documented and can be re-evaluated.
