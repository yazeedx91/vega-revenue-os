# DD-006: Revenue Analytics as Read-Model Context

- **Decision ID:** DD-006
- **Status:** Accepted
- **Date:** 2026-08-08
- **Owner:** Domain Architecture Board

## Decision

Revenue Analytics is a read-model bounded context. It consumes domain events from operational contexts and produces reports, dashboards, and KPIs. It does not own source aggregates.

## Context

Analytics requires data from many aggregates. Making it an operational context would create dependencies in the wrong direction.

## Alternatives

1. Analytics commands modify source aggregates
2. Analytics owns copies of data populated from events
3. Analytics queries source aggregates directly

## Rationale

Event-based projections (option 2) decouple analytics from operational consistency. Queries run against read models; source aggregates remain authoritative.

## Impact

- Analytics is eventually consistent.
- Operational contexts emit events; Analytics projects them.
- KPIs and reports are not authoritative for commands.
