# DD-003: AI Agent Management as Separate Bounded Context

- **Decision ID:** DD-003
- **Status:** Accepted
- **Date:** 2026-08-08
- **Owner:** Domain Architecture Board

## Decision

AI Agent Management is a separate bounded context from Mission Management and AI Governance. It owns agent identity, capabilities, versions, and execution lifecycle.

## Context

The business architecture treats agents as distinct actors. Mixing operational execution with governance and mission orchestration would create a bloated context.

## Alternatives

1. Agent logic inside Mission Management
2. Agent governance and execution in one context
3. Separate contexts for agent management, governance, and missions

## Rationale

Separating concerns allows agent execution to evolve independently from policy and mission orchestration. Governance provides rules; Mission Management provides objectives; Agent Management executes.

## Impact

- Clear contracts between Mission Management and AI Agent Management.
- Policies and autonomy rules are defined in AI Governance and consumed by both.
- Agent execution outcomes are published as events.
