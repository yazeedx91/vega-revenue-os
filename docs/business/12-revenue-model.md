# Revenue Model

## Pricing Alternatives Evaluated

| Model | Description | Strengths | Weaknesses |
|---|---|---|---|
| Subscription | Fixed monthly fee | Predictable revenue | Misaligned with value |
| Usage | Per action or contact | Scales with activity | May drive bad behavior |
| AI execution credits | Pre-purchased credits | Flexible, measurable | Complex billing |
| Per seat | Per user license | Simple | Does not reflect AI value |
| Per qualified meeting | Fee per booked meeting | Outcome-aligned | Attribution complexity |
| Per qualified opportunity | Fee per CRM opportunity | Strong outcome link | Longer sales cycle |
| Hybrid | Base + usage + outcome | Balanced | More complex to quote |
| Enterprise contract | Custom annual deal | Large ACV | Long sales cycle |

## Recommended Model

**Hypothesis: Hybrid Pricing**

- **Base platform subscription** for tenant access, configuration, and oversight
- **AI execution credits** for autonomous actions consumed
- **Outcome-linked fee** for qualified meetings or qualified opportunities, with clear attribution and customer approval

## Pricing Dimensions

- Tenant or customer
- Number of users or seats
- AI execution credits consumed
- Number of qualified meetings
- Number of qualified opportunities
- Data sources or enrichment volume
- Number of provider integrations

## Expansion Mechanisms

- Additional users and teams
- Additional geographies
- Additional ICP configurations
- Additional provider adapters
- Higher autonomy levels
- Advanced analytics and reporting

## Upsell Opportunities

- More credits
- More active missions
- Premium AI models
- Custom integrations
- Dedicated support

## Customer Lifetime Value Assumptions

- **Initial contract value**: to be validated with early customers
- **Annual expansion**: to be validated
- **Retention**: to be measured against mission success
- **Gross margin**: driven by AI cost efficiency; to be modeled

## Cost Drivers

- LLM provider usage
- Data and research APIs
- Cloud infrastructure
- Meeting provider usage
- Integration maintenance
- Compliance and security operations

## Gross-Margin Considerations

- High-margin: base subscription and AI execution credits
- Lower-margin: outcome-linked fees if attribution is disputed
- Margin improves with scale and model efficiency
