# ProjectX Production Environment Contract

All values in this document are names and formats. Real credentials, connection strings, and tokens must never be committed to Git.

## Classification Key

- **CONFIG**: Non-secret configuration; safe to source from IaC or CI/CD variables.
- **SECRET**: Sensitive value; must be stored in Azure Key Vault and injected at runtime.
- **GENERATED**: Value produced by the infrastructure (host, URL, connection string); should be stored in Key Vault by the deployment pipeline.
- **EXTERNAL_PROVIDER**: Endpoint, tenant, or identifier provided by an external Microsoft/cloud service.
- **OPTIONAL**: Not required for core operation.
