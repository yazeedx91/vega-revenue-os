# AID-006: Tool Output Trust and Validation Before Use

- **Decision ID:** AID-006
- **Status:** Proposed
- **Date:** 2026-08-08
- **Owner:** Chief AI Architect / AI Safety Architect

## Decision

Tool output is not automatically trusted. It must pass schema validation, tenant isolation, freshness, plausibility, PII, and malicious-content checks before being used by an agent or stored in memory/knowledge.

## Context

External systems can return malformed, stale, cross-tenant, or malicious data. Indirect prompt injection through tool output is a real threat.

## Rationale

Validating tool output prevents poisoning, hallucination, and unauthorized actions flowing from untrusted external data.

## Impact

- Tool Gateway performs output validation.
- Agents receive validated, summarized, attributed outputs.
- Malicious or unsupported content is quarantined.
- Tool output does not bypass policy or memory write rules.
