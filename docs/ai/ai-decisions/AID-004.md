# AID-004: Memory Authority: Memory Cannot Override Policy or Permission

- **Decision ID:** AID-004
- **Status:** Proposed
- **Date:** 2026-08-08
- **Owner:** Chief AI Architect / AI Safety Architect

## Decision

Memory is a source of context, not authority. Agents cannot write arbitrary model outputs to long-term memory. Memory cannot override security, authorization, policy, or tenant boundaries. Memory writes require validation, authorization, and versioning.

## Context

Untrusted memory writes are a primary poisoning and privilege escalation risk. The architecture must prevent remembered information from becoming permission.

## Rationale

Strict memory write policy protects against poisoning, exfiltration, and unauthorized behavior while still allowing useful learning.

## Impact

- Memory Write Service validates content, evidence, confidence, and conflicts.
- Policy Engine authorizes writes.
- Versioned memory updates support audit and correction.
- Runtime checks ensure memory never overrides policy.
