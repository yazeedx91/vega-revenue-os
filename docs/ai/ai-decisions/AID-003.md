# AID-003: Context Engineering with Token Budgets and Tenant Isolation

- **Decision ID:** AID-003
- **Status:** Proposed
- **Date:** 2026-08-08
- **Owner:** Chief AI Architect

## Decision

Context assembly will be an explicit pipeline: gather, filter by tenant, rank by relevance, deduplicate, summarize, compress, validate, and assemble. Each task has a token budget. Context is never indiscriminately dumped into the model.

## Context

Unbounded context leads to high cost, latency, distraction, and risk of cross-tenant leakage or irrelevant inputs. The architecture must control what the model sees.

## Rationale

Explicit context engineering improves cost, quality, safety, and observability. Tenant isolation is non-negotiable.

## Impact

- Context Assembler becomes a defined runtime component.
- Token budgets per task/mission/tenant.
- Summarization and ranking strategies are versioned and evaluated.
- Security filters prevent leakage.
