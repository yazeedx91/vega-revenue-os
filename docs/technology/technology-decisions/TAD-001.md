# TAD-001: Microsoft Azure as Primary Cloud Platform

- **Decision ID:** TAD-001
- **Status:** Proposed
- **Date:** 2026-08-08
- **Owner:** CTO / Cloud Architect

## Decision

Microsoft Azure is the primary cloud platform for production deployment.

## Context

The initial specialization is Microsoft Dynamics 365 ERP sales. The Microsoft ecosystem (Dynamics 365, Dataverse, Microsoft Graph, Entra ID, Azure OpenAI) provides operational, security, and integration advantages.

## Alternatives

- AWS as primary: strong general-purpose cloud, but extra identity federation and Dynamics integration effort.
- GCP as primary: strong AI/ML, but weaker Microsoft ecosystem integration.
- Multi-cloud primary: adds complexity before scale is proven.

## Rationale

Azure is a hard organizational constraint. It aligns with Dynamics 365, Entra ID, Graph, Azure OpenAI, and enterprise compliance. AWS and GCP are documented as migration/lock-in alternatives.

## Impact

- Native integration with Microsoft services.
- Managed identities reduce secret sprawl.
- Microsoft identity and security model applies end-to-end.
- AWS/GCP portability preserved via adapters and containers.

## Conditions for Reconsideration

Genuine architectural contradiction discovered that Azure cannot satisfy (documented as Proposed ADR).
