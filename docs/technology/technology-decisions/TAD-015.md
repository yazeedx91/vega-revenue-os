# TAD-015: Bicep as Primary Infrastructure-as-Code

- **Decision ID:** TAD-015
- **Status:** Proposed
- **Date:** 2026-08-08
- **Owner:** DevOps / Platform Architect

## Decision

Bicep is the primary IaC language for Azure resources.

## Context

Azure-first deployment requires native, declarative IaC without state file management.

## Alternatives

- Terraform: cross-cloud but state file overhead.
- Pulumi: programmatic, adds complexity.
- ARM templates: verbose.

## Rationale

Bicep compiles to ARM, is type-safe, supports modules, and has no separate state file.

## Impact

- Faster Azure deployments.
- Easier maintenance than ARM.
- Terraform reserved for cross-cloud abstractions if needed.
