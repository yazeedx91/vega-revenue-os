# TAD-013: Azure Key Vault for Secrets

- **Decision ID:** TAD-013
- **Status:** Proposed
- **Date:** 2026-08-08
- **Owner:** Security Architect

## Decision

Azure Key Vault stores all secrets, API keys, certificates, and customer-managed keys.

## Context

Centralized, auditable secret management is required.

## Alternatives

- AWS Secrets Manager: not Azure-native.
- HashiCorp Vault: high operational overhead.
- Azure App Configuration: not for secrets.

## Rationale

Key Vault integrates with Managed Identities, Private Endpoints, and Azure RBAC, providing secure, auditable secret storage.

## Impact

- No secrets in code or config.
- Automated rotation support.
- Audit logs in Azure Monitor.
