# TAD-018: Azure Communication Services Email + Microsoft Graph for Email

- **Decision ID:** TAD-018
- **Status:** Proposed
- **Date:** 2026-08-08
- **Owner:** Integration Architect

## Decision

Azure Communication Services Email is the primary transactional email provider. Microsoft Graph is used for send-as-user scenarios. SendGrid is a fallback adapter.

## Context

Email is a primary outreach channel. Azure-native email aligns with the Azure-first strategy.

## Alternatives

- SendGrid primary: popular but adds separate vendor.
- Mailgun: similar.
- Microsoft Graph only: not designed for bulk transactional email.

## Rationale

Azure Communication Services provides managed transactional email with Azure integration. Microsoft Graph handles user-mailbox sends. SendGrid fallback preserves resilience.

## Impact

- Email Gateway abstracts provider details.
- Suppression, bounce, and delivery tracking handled.
- Tenant-scoped sending domains possible.
