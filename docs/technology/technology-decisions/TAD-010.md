# TAD-010: Azure OpenAI as Primary LLM Provider with Gateway Abstraction

- **Decision ID:** TAD-010
- **Status:** Proposed
- **Date:** 2026-08-08
- **Owner:** AI Infrastructure Architect

## Decision

Azure OpenAI Service is the primary LLM provider. A custom TypeScript LLM Gateway abstracts provider details and supports OpenAI and Anthropic fallbacks.

## Context

Enterprise data handling, private networking, content filtering, and Azure integration favor Azure OpenAI, but provider abstraction is required.

## Alternatives

- OpenAI direct: less enterprise control.
- Anthropic primary: not Azure-native.
- Google Vertex AI: less Microsoft ecosystem integration.

## Rationale

Azure OpenAI aligns with Azure-first strategy and enterprise requirements. The gateway preserves replaceability and routing flexibility.

## Impact

- Private endpoints and managed identity possible.
- Fallback providers maintain resilience.
- Cost and token tracking centralized.

## Conditions for Reconsideration

Quota, feature, or cost issues make Azure OpenAI unsuitable; fallback becomes primary.
