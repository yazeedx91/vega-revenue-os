# TAD-014: OpenTelemetry + Azure Monitor for Observability

- **Decision ID:** TAD-014
- **Status:** Proposed
- **Date:** 2026-08-08
- **Owner:** SRE / DevOps Architect

## Decision

Use OpenTelemetry for instrumentation and Azure Monitor Application Insights / Log Analytics as the backend.

## Context

Vendor-neutral instrumentation with Azure-native backend balances portability and integration.

## Alternatives

- Prometheus/Grafana: requires self-managed infrastructure.
- Datadog/New Relic: third-party cost and lock-in.
- Azure Monitor SDK only: less portable.

## Rationale

OpenTelemetry is the industry standard. Azure Monitor provides APM, logging, metrics, and alerting with native Azure integration.

## Impact

- Consistent telemetry across all services.
- Tenant-scoped dimensions.
- AI-specific metrics tracked.
