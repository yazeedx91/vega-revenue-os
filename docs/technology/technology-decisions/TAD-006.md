# TAD-006: Azure Service Bus as Event Infrastructure

- **Decision ID:** TAD-006
- **Status:** Proposed
- **Date:** 2026-08-08
- **Owner:** Distributed Systems Engineer

## Decision

Azure Service Bus Premium is the primary event bus for commands, domain events, and integration events.

## Context

The system needs durable, ordered, delayed, and dead-letter capable messaging with multi-tenant semantics.

## Alternatives

- Azure Event Hubs: excellent streaming, but lacks native DLQ and scheduled messages.
- Kafka on AKS: high operational burden.
- Redis Streams: limited durability and ordering guarantees.

## Rationale

Service Bus Premium provides queues, topics, sessions, scheduled messages, DLQ, transactions, and geo-DR, matching the event-driven architecture requirements.

## Impact

- Central messaging backbone for all bounded contexts.
- Tenant context propagated in messages.
- DLQ and replay support.

## Conditions for Reconsideration

Throughput exceeds Service Bus Premium limits; evaluate Event Hubs or Kafka.
