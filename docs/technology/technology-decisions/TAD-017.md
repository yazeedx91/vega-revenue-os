# TAD-017: GitHub Actions + Azure Deployment Environments for CI/CD

- **Decision ID:** TAD-017
- **Status:** Proposed
- **Date:** 2026-08-08
- **Owner:** DevOps / Platform Architect

## Decision

GitHub Actions is the CI/CD platform, deploying to Azure Container Registry and Azure Container Apps via OIDC federated credentials.

## Context

Widely adopted, integrates with Azure, supports OIDC for secret-less Azure authentication.

## Alternatives

- Azure DevOps Pipelines: native but less GitHub-native.
- GitLab CI: strong but not organizational preference.
- CircleCI: good but less Azure integration.

## Rationale

GitHub Actions + OIDC + Azure Deployment Environments provides secure, auditable, and flexible deployment pipelines.

## Impact

- No long-lived secrets in CI.
- Automated build, test, scan, deploy.
- Environment protection rules.
