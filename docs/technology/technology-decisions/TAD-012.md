# TAD-012: Microsoft Entra ID for Identity

- **Decision ID:** TAD-012
- **Status:** Proposed
- **Date:** 2026-08-08
- **Owner:** Security Architect

## Decision

Microsoft Entra ID is the identity provider for workforce users, service principals, and managed identities.

## Context

Azure-first, Dynamics 365, and Microsoft Graph integration require enterprise identity.

## Alternatives

- Auth0/Okta: require federation and extra integration.
- Keycloak: self-hosted operational burden.

## Rationale

Entra ID integrates natively with Azure, API Management, Azure OpenAI, Dynamics 365, and managed identities.

## Impact

- SSO for users.
- Managed identities for services.
- Conditional access and MFA.
- Customer tenants federated via multi-tenant app registration.
