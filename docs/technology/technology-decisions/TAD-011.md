# TAD-011: Custom TypeScript Agent Runtime over Off-the-Shelf Agent Framework

- **Decision ID:** TAD-011
- **Status:** Proposed
- **Date:** 2026-08-08
- **Owner:** Chief AI Architect

## Decision

Build a custom TypeScript specialist-agent runtime rather than adopting LangGraph, Semantic Kernel, or OpenAI Agents SDK as the architecture owner.

## Context

The approved AI topology and policy boundaries must remain controlled by the domain architecture.

## Alternatives

- LangGraph/LangChain: would impose its own multi-agent graph and risk bypassing policy.
- Semantic Kernel: TypeScript support is not production-ready.
- OpenAI Agents SDK: provider-specific.

## Rationale

A custom runtime enforces the Mission Orchestrator → Planner → Specialist Agents → Policy → Tool Gateway flow and prevents framework lock-in.

## Impact

- Domain architecture remains primary.
- Libraries used only for narrow tasks (LLM clients, parsers).
- More initial development but better long-term control.

## Conditions for Reconsideration

A mature framework emerges that natively supports the exact topology and policy model without lock-in.
