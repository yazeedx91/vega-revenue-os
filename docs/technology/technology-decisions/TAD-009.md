# TAD-009: Azure Blob Storage for Object Storage

- **Decision ID:** TAD-009
- **Status:** Proposed
- **Date:** 2026-08-08
- **Owner:** Cloud Architect

## Decision

Azure Blob Storage is the object storage for documents, research artifacts, attachments, exports, and archives.

## Context

Requires durable, scalable, tenant-isolated object storage with lifecycle management.

## Alternatives

- Azure Files: not ideal for object-style access patterns.
- S3 via adapter: adds provider complexity.
- GCS via adapter: adds provider complexity.

## Rationale

Azure Blob Storage is native, cost-effective, supports tiers, lifecycle, encryption, and private endpoints.

## Impact

- Tenant-scoped prefixes enforce isolation.
- Lifecycle policies reduce cost.
- CMK support for compliance.
