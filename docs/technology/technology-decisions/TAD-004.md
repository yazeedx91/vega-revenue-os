# TAD-004: Azure Database for PostgreSQL Flexible Server as Primary Database

- **Decision ID:** TAD-004
- **Status:** Proposed
- **Date:** 2026-08-08
- **Owner:** Data Architect

## Decision

Azure Database for PostgreSQL Flexible Server is the primary transactional database, including the pgvector extension.

## Context

The domain model is relational/DDD-oriented. Tenant isolation, ACID, JSONB flexibility, and vector support are needed.

## Alternatives

- Azure SQL: lacks pgvector; lock-in to Microsoft SQL dialect.
- Azure Cosmos DB: document model diverges from DDD aggregates; no native vector.
- Self-managed PostgreSQL on AKS: unnecessary operational burden.

## Rationale

PostgreSQL is open, mature, supports RLS, JSONB, and pgvector. The Flexible Server managed offering reduces operations while preserving portability.

## Impact

- Single managed service for OLTP and initial vector search.
- RLS enforces tenant isolation.
- Read replicas and PITR for reliability.
- Path to Azure AI Search if vector scale grows.

## Conditions for Reconsideration

Vector query performance exceeds pgvector capacity at target scale; add Azure AI Search.
